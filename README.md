# Таємниці Світу // ARG Web Portal

> [!IMPORTANT]
> **ЗАСЕКРЕТЕРИЙ БАЗОВИЙ ТЕРМІНАЛ ОРГАНІЗАЦІЇ**  
> Доступ дозволено лише оперативникам з відповідним рівнем допуску. Усі дії та переходи протоколюються.

---

## 🌐 Швидкі посилання

* **Офіційний веб-портал:** [Перейти до термінала](https://vadymhusarovv-stack.github.io/secret-organization/)
* **Мережевий хаб:** Управління зовнішніми вузлами зв'язку (Steam, Telegram, Viber).
* **Система допусків:** Реєстр військових звань, спецролей та системних рівнів безпеки.

---

## 🛠️ Стек технологій проєкту

Портал побудований на сучасних, легких та ефективних інструментах без зайвого роздування:

* **HTML5 & CSS3** — кастомна адаптивна верстка з фірмовою кібер-темою, шрифтами *JetBrains Mono*, анімованими кнопками та темним інтерфейсом термінала.
* **JavaScript** — легкі клієнтські скрипти для маршрутизації та обробки інтерфейсу.
* **GitHub Pages & Actions** — автоматизована публікація сайту та безперервний деплой.

## 📁 Структура репозиторія

| Директорія / Файл | Опис компонента |
| :--- | :--- |
| `index.html` | Головна сторінка проекту та точка входу в термінал. |
| `links.html` | Центральний каталог усіх доступних зовнішніх посилань та розділів. |
| `networks.html` | Мережевий хаб для переходу на платформи зв'язку. |
| `clearance.html` | Реєстр системних рівнів допуску та військової ієрархії. |
| `archive.html` | Засекречений архів матеріалів та історичних даних. |
| `steam.html` | Зовнішній вузол зв'язку для платформи Steam. |
| `telegram.html` | Блок із 4-х оперативних каналів та чатів у Telegram. |
| `viber.html` | Резервний частотний діапазон (спільнота та канал у Viber). |
| `favicon.png` | Фірмовий неоновий кіберпанк-логотип організації («TC»). |
| `styla.css` | Основний файл стилів вебпорталу з кібер-темою. |

## 🔒 Про організацію

«Таємниці Світу» — це інтерактивний ARG-проєкт, що поєднує глибокий лор, кібернетичний дизайн та розгалужену мережу комунікаційних каналів. Кожен оперативник може зануритися у внутрішні протоколи, дослідити структуру допусків та знайти приховані сліди нашої цивілізації.
